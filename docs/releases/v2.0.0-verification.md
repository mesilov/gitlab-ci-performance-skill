## Published-asset installation and update

After downloading the release asset, unpack it into an empty temporary project,
create a fresh Python 3.10 venv and install only the declared requirements. All
**100 downloaded tests passed**. `tests/test_installed_skill.py` copies only the
skill directory, supplies a standalone synthetic glab transport, and exercises
`collect → collect-details → report → render`. It checks metadata/trace request
bounds, unavailable states, privacy sentinels, payload size, saved JSON validation,
byte-identical offline re-rendering and directory replacement.

The copied installed helper also rendered saved 1.0 and 2.0 reports in both
languages; replacing the installed directory reproduced the saved 2.0 Russian
report byte-for-byte. No repository module path was needed by the installed CLI.

A separate upgrade used the real old runtime from main commit
`ec247f74dae2f24c8c594628adbebc2bc8452203` (report 1.1), generated exact-ref history
and Russian HTML, then backed up that skill directory and copied the downloaded
2.0 directory into its place. Existing `.codex/skills` and `.claude/skills` symlinks
still resolved. Re-rendering the saved 1.1 report produced byte-identical HTML;
the same installed helper then rendered the new 2.0 report.

## Browser and bounded-data evidence

Offline en/ru browser tests selected every one of 110 retained synthetic attempts
from 126 source attempts, including distinct reruns and every supported outcome.
Both windows, Older/Newer/Latest, job isolation, priorities/evidence navigation,
queue ordering/colors, explicit units and keyboard selection passed. The densest
64-attempt chart fit 320/375/1280 px in light/dark modes without page/chart overflow.
Moved standalone HTML rendered without companion files, network or console errors.

The saved synthetic metadata records 110 fresh metadata requests and **95 trace
requests**, all limited to retained IDs. Coverage: 77 available, 2 partial, 8 empty,
9 erased, 6 not-run and 8 unavailable traces. Received trace bytes: 51369. Workers:
4; cap: 32 MiB per trace. Each HTML is below 0.8 MiB and contains no raw trace text
or secret sentinel. These measurements describe the synthetic fixture, not a
performance claim for a real GitLab installation.

Independent collection/parser and calculation/contract reviews were completed.
Confirmed findings were reproduced with failing tests before fixes, then re-reviewed.
Cross-version CI additionally exposed fractional timestamp parsing and float-sum
reproducibility; normalization and `math.fsum` regressions now pass on Python 3.10.

PR #13 remains the main-branch integration step; the public release is pinned to
the validated runtime commit. Subsequent release-evidence documentation does not
