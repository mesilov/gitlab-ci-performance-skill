Method and compatibility
Schema/calculation 2.0.0. Each point uses one pipeline identity. Outcomes use the latest retained attempt; timing includes every retained attempt. A baseline needs at least three preceding comparable successful complete measurements, up to ten. A zero baseline has no defined percentage. Configuration coverage is explicit. Cross-pipeline chains are unsupported. JSON is always in seconds; the selected series and metric switch to minutes only above 300 seconds. v1 job-only artifacts retain their original calculation.
